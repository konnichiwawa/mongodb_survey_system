# 测试用例

## 一、测试目的

本测试用于验证基于 MongoDB 的问卷系统的主要功能是否符合设计要求，重点测试用户认证、问卷创建、题目添加、条件跳转、答案校验、答卷提交和统计查询等功能。

本次测试以 API 自动化测试为主，使用 pytest 执行 `tests/test_api.py` 中的测试用例，并结合测试执行结果记录系统表现。

## 二、测试环境

| 项目 | 配置 |
|---|---|
| 操作系统 | Windows |
| Python 版本 | Python 3.14.7 |
| 测试框架 | pytest 9.1.1 |
| 数据库 | MongoDB 8.3.11 |
| Python 运行环境 | 项目虚拟环境 `.venv` |
| 自动化测试文件 | `tests/test_api.py` |
| 测试数据库 | `survey_system_test` |
| 测试方式 | API 自动化测试 |

测试前，通过 `mongosh` 确认本机 MongoDB 服务能够正常连接。随后在项目虚拟环境中执行自动化测试。

## 三、测试方法与范围

本项目采用 API 自动化测试方式，通过测试客户端调用后端接口，检查接口返回状态、业务处理结果以及数据校验行为。

本次已执行的测试覆盖以下内容：

1. 健康检查。
2. 用户注册、登录和当前用户查询。
3. 重复用户名注册处理。
4. 未登录访问问卷管理接口。
5. 创建问卷、添加题目、发布问卷和访问分享链接。
6. 题目重复选项校验。
7. 答卷提交和统计查询。
8. 非法答案校验。
9. 单选题条件跳转。
